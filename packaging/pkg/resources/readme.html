About the microphone permission

To record, Fitzrovia Records DAW needs access to audio input (your microphone, guitar or audio interface). macOS does not allow any installer to grant this permission in advance. Instead:

  1. The first time you open Fitzrovia Records DAW, a welcome screen explains why audio input is needed.
  2. Click Allow Audio Input… and then OK in the macOS dialog.

If you clicked Don't Allow by mistake, open System Settings › Privacy & Security › Microphone and switch Fitzrovia Records DAW on, or use Help › Setup & Permissions inside Fitzrovia Records DAW.

Opening an unsigned build

If macOS says Fitzrovia Records DAW “cannot be opened because Apple cannot check it”, Control-click the app in Applications, choose Open, then Open again (or click Open Anyway in System Settings › Privacy & Security).

Uninstalling

Drag Applications › Fitzrovia Records DAW to the Trash. Your projects in Music › Fitzrovia Records DAW are kept.
