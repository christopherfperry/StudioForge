Read Me — Fitzrovia Records DAW @VERSION@

What's new in 0.6

  • Mute, solo and arm buttons respond anywhere on the coloured box. Muted or solo-silenced tracks are dimmed and labelled; muted clips are dimmed and struck through.
  • Exports match what you hear: soloed-out and muted tracks no longer leak into bounces.
  • Delete tracks and stems with the trash button, the right-click menu or ⌘⌫ (every delete can be undone with ⌘Z). Edit › Delete All Stems removes a whole split.
  • Easier volume: mixer faders with a 0 dB mark and dB readout, double-click to reset, ⌥⌘↑ / ⌥⌘↓ for the selected track.
  • Genre-matched synth tones for Generate Matching Synth (10 genres or auto-detect).
  • Typing in a text field (e.g. renaming a track) no longer triggers single-key shortcuts; you're asked before unsaved changes are discarded.

Microphone permission

macOS does not allow any installer to grant audio-input access in advance. The first time you open the app, a welcome screen explains why it is needed: click Allow Audio Input… and then OK. If you clicked Don't Allow, open System Settings › Privacy & Security › Microphone and switch Fitzrovia Records DAW on, or use Help › Setup & Permissions inside the app.

Opening an unsigned build

The app installed by this package is not quarantined and opens normally. If macOS ever says it could not verify Fitzrovia Records DAW, open System Settings › Privacy & Security, click Open Anyway and enter your password. (On macOS 15 Sequoia and later, Control-click › Open no longer bypasses this; on macOS 13–14 it still works.)

Uninstalling

Drag Applications › Fitzrovia Records DAW to the Trash. Your projects in Music › Fitzrovia Records DAW are kept.
